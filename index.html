할 일을 정리하고 중요도·긴급도·예상 시간을 바탕으로 우선순위를 계산합니다. 공개 버전은 방문자의 GitHub 토큰이나 API 키를 요구·저장·전송하지 않습니다.

🔐 공개 배포 보안 원칙

초기 프로토타입은 GitHub Models API를 이용한 AI 분석을 구현했습니다. 그러나 정적 웹앱에서 방문자의 PAT를 직접 취급하는 구조는 공개 포트폴리오에 적합하지 않다고 판단했습니다.

현재 공개판: 토큰 입력 없음 · API 키 없음 · 외부 AI 요청 없음 · 서버 전송 없음. 모든 우선순위 계산은 이 페이지의 명시적인 규칙으로 브라우저에서 수행됩니다.

할 일 추가

우선순위 = 중요도 × 3 + 긴급도 × 3 + 짧은 작업 보너스. AI가 아닌 투명한 규칙 기반 계산입니다.

오늘의 우선순위

Why no AI in the public build?

AI 기능을 구현하지 못해서 제거한 것이 아닙니다. 초기 AI 프로토타입을 검토한 뒤, 정적 클라이언트가 사용자의 credential을 직접 처리하는 위험을 공개 배포보다 우선하지 않기로 결정했습니다. 실제 서비스로 확장한다면 인증과 AI 요청을 백엔드/BFF로 이동하고 서버 측 secret 관리와 접근 제어를 적용하는 구조가 필요합니다.

No credentials · No external API calls · Local rule-based prioritization
