Why no AI in the public build?

초기 AI 프로토타입의 데이터 흐름과 credential 처리 방식을 검토한 뒤, 정적 클라이언트에서 사용자의 credential을 직접 취급하지 않는 것을 공개 배포 원칙으로 선택했습니다. 실제 서비스로 확장한다면 인증과 AI 요청을 backend/BFF로 이동하고 서버 측 secret 관리와 접근 제어를 적용합니다.

1AI 프로토타입 구현 및 동작 검증
2PAT 저장·전송과 클라이언트 노출 위험 검토
3공개판에서 credential-dependent 기능 제거 결정
4토큰 없는 로컬 규칙 기반 버전으로 GitHub Pages 배포
